# 路线图与优先级

## 近期：补齐真实医学垂直切片

1. 完成 Emu3.5 固定权重、视觉 tokenizer、FlashAttention 与 CFG 生成验收。
2. 增加专家标注报告生成切片，验证事实、否定、矛盾和关键发现。
3. 增加公开定位/测量模型与数据切片。
4. 在真实临床安全偏好数据上验证至少一条高级后训练路线。

## 中期：从单节点到平台规模

1. 多节点 vLLM/SGLang 与长时间负载稳定性。
2. 多节点 FSDP/DeepSpeed 医学对齐训练。
3. 把资源目录中不同架构和领域的代表条目升级为 runtime validated。
4. 自动生成可签名的复现包、公开排行榜清单和版本化文档。

## 长期：规模超过通用工具包

按医学领域建立“模型 + 数据 + 基准 + 配方 + 证据”的完整切片，而不是只增加名字：放射、病理、眼科、皮肤、内镜、超声、医学视频、医学文档、3D 和纵向多模态记录。

## 排序原则

优先处理能够增加架构多样性、医学任务覆盖、治理能力或真实验证等级的工作。相同执行器下再增加一个未运行模型，优先级低于补齐一个新领域的真实评测闭环。
